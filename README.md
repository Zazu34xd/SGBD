# SGBD
Taller de bases de datos

## Descripción del Proyecto
Este repositorio tiene como objetivo almacenar y gestionar todos los scripts, modelos relacionales y prácticas desarrolladas durante la materia de Taller de Bases de Datos. El enfoque principal es la aplicación práctica de lenguajes SQL (DDL, DML, DCL, TCL) en la creación, manipulación y administración de Sistemas de Gestión de Bases de Datos (SGBD).

## Estructura del Repositorio
El proyecto está organizado en las siguientes carpetas y archivos para mantener un orden lógico:

*   `/practica_01_/` - Documentación y fundamentos teóricos sobre SGBD.
*   `/practica_02_/` - Scripts de creación de estructuras (CREATE, ALTER, DROP).
*   `/practica_03_/` - Ejemplos de implementación de llaves primarias, foráneas y reglas de integridad.
*   `README.md` - Archivo principal de documentación del proyecto.

## Cómo ejecutar o revisar el proyecto
Para probar los scripts contenidos en este repositorio, sigue estos pasos:

1. Clonar el repositorio en tu máquina local usando Git.
2. Abrir el gestor de base de datos de tu preferencia (se recomienda **MySQL Workbench**).
3. Abrir el archivo `.sql` correspondiente a la práctica que deseas revisar.
4. Ejecutar el código paso a paso, asegurándote de correr primero las sentencias `CREATE DATABASE` y las tablas principales antes que las tablas dependientes.
